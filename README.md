# Bacterial_Lipidome_Atlas
This repository contains MSP files for bacterial lipid　identification in MS-DIAL.

## Contents
- `MSP/` — MSP files for lipid identification

## Usage
When analyzing untargeted lipidomics data in MS-DIAL, select the MSP file you want to use for identification in the Identification tab.
